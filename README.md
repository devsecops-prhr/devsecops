# DevSecOps

Pipeline de integração e segurança para desenvolvimento seguro.

## Sobre

Projeto para automatizar práticas de segurança no ciclo de vida do software (CI/CD), incluindo análise estática, escaneamento de segredos, verificação de dependências e build/testes automatizados.

## Funcionalidades

- CI/CD via GitHub Actions
- Análise estática de código (SAST)
- Escaneamento de segredos
- Verificação de dependências vulneráveis
- Build e testes automatizados
